# 里程碑与风险清单

## 里程碑

| 阶段 | 目标 | 状态 |
| --- | --- | --- |

| M2 | 双索引混合检索 + 术语扩展 | 已完成 |

| M4 | 任务板 + 周报自动生成 | 进行中 |

| M6 | 万级数据压测与参数复核 | 待开始 |

## 主要风险

1. **评测标注主观**：gold 区间由单人标注，召回率数字可能偏高。缓解：双人交叉标注，计算一致性。
2. **数据规模**：百级片段下参数结论不能直接外推到万级。缓解：预留 M6，先压测再定 `M` 与 `efSearch`。
3. **单进程限制**：嵌入式 seekdb 在一个进程内独占数据目录，Web 服务与命令行同时写会冲突。缓解：文档写清楚，服务端统一走 API。
4. **向量语义能力边界**：本地哈希向量只能覆盖词面相近，真正的同义改写靠术语表。缓解：术语表持续补充，对外表述不夸大「语义检索」。
5. **时间风险**：周报与网站排在同一周，容易赶工。缓解：网站数据由命令导出，避免手工维护两份。

## 下周要确认的事

- 512 字节预算下证据包是否还能放下一整条证据。
- 网站上的演示数据是否全部来自真实查询（不能有手写假数据）。
- 任务板状态流转是否需要限制（比如「已完成」不能直接回退到「待开始」）。
