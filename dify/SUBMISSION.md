## 一句话

《忘川酒馆》是一个用 Dify Chatflow 编排的中文文字酒馆游戏：玩家每发一句话就是一回合，
三个 NPC 会把玩家做过的事写进 seekdb 的记忆表，下次开口他们记得。

## 玩法与规则（三条，均可在演示中当场验证）

1. **一杯酒换一个秘密**——请任意 NPC 喝一杯酒，他会多说一句只在杯边说的事；
2. **酒钱不能欠**——说「赊账」会被当场回绝；
3. **动手要记账**——偷东西、威胁人都会记一笔，记到第三次就被逐出酒馆（结局：逐客）。

除这三条外，还能偷、偷看、讲故事、道歉、夸人、骂人、讲价、挪地方；
每个动作的成败由后端按确定性骰子结算，**同一个玩家在同一回合做同一件事，结果必然相同**。

## 技术分工

| 组件 | 在作品里干什么 |
| --- | --- |
| **Dify（Chatflow，11 节点）** | 编排：LLM 把一句话拆成结构化动作 → IF 判断是否「读心」→ HTTP 调后端结算 → LLM 把判定写成小说 → 拼「事实行」输出 |
| **OceanBase seekdb 1.4** | 唯一事实源：玩家账本、NPC 记忆（`FULLTEXT ngram` + `VECTOR HNSW` 双索引，RRF 融合）、事件流水、物品与好感 |
| **PowerContext 1.5** | 每局结束时把这一局写成一条「传说」存进长期记忆；下次新会话先读它。关掉不影响玩法（seekdb 的 `tw_legend` 是主来源） |

## 第一句话建议发什么

| 发送 | 会看到 |
| --- | --- |
| `要一壶桂花酿。` | 【判定：成功】+【阿箬的杯边话】+ 铜板 17 |
| `先赊一壶桂花酿。` | 【判定：不成】「本店不赊账。」 |
| 连发三次 `拍桌子吓唬阿箬。` | 被记账 1→2→3，第三次【判定：被逐出】+ 结局：逐客 |
| `打烊了，我该走了。` 然后 `我又来了。` | 【判定：只是看着】第二天… +【酒馆记得你】 |
| `读心，看看阿箬现在在想什么。` | 她脑子里真实的记忆行（亲历/目击/传闻/旧事） |
