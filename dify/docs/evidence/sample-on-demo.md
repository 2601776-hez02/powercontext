## 一个容易踩的坑

跑之前发现演示后端上的「无名客」已经累积到**第 10 回合、18 铜板**——照抄样例的人会看到
完全不同的数字（这正是"结果与声明不符"最容易发生的场景）。

处理：
1. 把演示后端上这些常用名字（无名客 / 演示 / 测试 / 评审 / guest）**重置**了一遍；
2. README 第 8 节补一句：在在线演示上照着做时**填一个没用过的名字**，就会从第 1 回合开始、数字与表一致。
