# 中文全文检索与 ngram 分词

英文靠空格切词，中文没有天然分隔符，所以中文全文检索必须先分词再建倒排。seekdb 提供了几种分析器，其中最适合“零配置中文”的是 ngram：它把连续字符切成固定长度的片段。设置 `ngram_token_size=2` 时，“向量数据库”会被切成“向量”“量数”“数据”“据库”四个二元组，查询词同样切分后求交集，因此能容忍一部分切分边界的差异。

全文检索的写法是 `MATCH(document) AGAINST ('向量数据库' IN NATURAL LANGUAGE MODE)`。它返回的是相关度分数而不是布尔值，可以直接 `ORDER BY` 排序；如果只想过滤，可以写成 `WHERE MATCH(...) AGAINST (...) > 0`。

ngram 的取舍：

- token 越长，区分度越高，误召回越少，但对短查询更不友好；
- token 越短，召回越高，噪声也越多；
- 二元组是中文场景的常用折中，配合向量检索能把“词面命中”和“语义相近”两路优势叠加起来。

需要注意的是，全文索引同样存在可见性延迟，批量导入后要等索引刷新完成，新片段才会出现在 MATCH 结果里。
