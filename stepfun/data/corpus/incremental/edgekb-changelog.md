# EdgeKB 版本记录

**1.0.0**：跑通最小闭环——浏览器用 Transformers.js + ONNX Runtime Web 做 INT8 量化 embedding，服务端用 seekdb-js 写入 `kb_chunks` 集合，检索走 `hybridSearch` 的单条 SQL。

**1.1.0**：加入 FP16 / FP32 精度切换，用于量化前后的体积与质量对比；新增后端选择（自动 / 强制 WebGPU / 强制 WASM）与降级提示。

**1.2.0**：新增增量导入——新文档按 `docId#chunkIndex` 生成稳定 id，`upsert` 覆盖写入后调用一次索引刷新，界面上的片段数即时更新。

**1.3.0**：把检索语句与逐条耗时展示到界面上；新增基准面板，固定查询集多轮取中位数与 P95。

**已知限制**：同一数据目录只能被一个进程打开；嵌入式模式不支持多实例并发写。超长文档（单段超过 480 字符）会被硬切，可能出现语义不完整。
